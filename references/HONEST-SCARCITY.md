# Honest Scarcity and Invite Only Levels

Scarcity works because it's a signal: "this is limited, so it's probably valuable". Fake scarcity destroys that signal the moment one customer notices, and it can break consumer protection law (for example rules against false urgency in the US, UK, EU and India).

**The test:** could you explain the limit to a customer face to face, and would it still be true next month?

## Real limits you can use

| Real limit | How to say it |
| --- | --- |
| **Your own time** | "I do these myself, so I take 4 a month." |
| **Physical capacity** | "We have 1 oven that fits wedding cakes, so 3 per weekend." |
| **Quality limit** | "Each one gets 2 weeks of attention, so I start 2 at a time." |
| **Real stock** | "Made in batches of 50. This batch: 12 left." (update it honestly) |
| **A real deadline** | "Prices go up on 1 January." (and then they really do) |
| **Fit** | "By application, because it only works for clinics already doing 100+ visits a month." |
| **Seasonal** | "Only available until the festival season ends." |

## Invite only, done honestly

"Invite only" or "by application" is fine when:
- There's a real reason you choose who you work with (fit, safety, capacity, your personal time).
- You actually say no to people who don't fit.
- You can explain the criteria in one sentence.

How to present it:
```
[Level 3 name]: by application
For [who it's for]. I take [real number] a month because [real reason].
Apply here and I'll reply within [real time] with a yes, a no, or a better option.
```

## Never do this

- A countdown timer that resets when the page reloads.
- "Only 2 spots left" when there's no real limit.
- "Price goes up tomorrow" when it doesn't.
- "Invite only" for something anyone who pays gets.
- Fake "sold out" to create demand.
- Pretending a level exists when you'd never deliver it.

## When customers push back

"Why is it limited?" Answer with the real reason, plainly. If you can't, it's not real scarcity.
